HOW TO READ THE RANKINGS

Each ranking answers a different question.

All views use the same battle archive, but each one measures something different.

A / STANDINGS

Points over time

Team and player standings add points from numbered battles in the archive. Monthly periods use UTC calendar months; seasons follow fixed blocks of 50 official battle numbers.

B / CONTRIBUTORS

Listed team contribution

The contributor list adds up the points shown for each player in team results. A player may have played for different teams in different battles.

C / PERFORMANCE INDEX

Performance Index

Each result is changed to a score from 0 to 100. The parts are then combined using the weights shown above. The PI is only a statistic, not an official Lichess rating.
