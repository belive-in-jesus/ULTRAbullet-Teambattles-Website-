READ THE RESULTS CORRECTLY

Different rankings, different questions.

These views use the same underlying competition archive, but they do not measure the same thing.

A / STANDINGS

Points over time

Team and player standings add points from eligible numbered battles. Monthly periods use UTC calendar months; seasons follow fixed blocks of 50 official battle numbers.

B / CONTRIBUTORS

Listed team contribution

The contributor view sums players’ listed contribution points across team-battle results. A player may have represented different teams in different battles.

C / PERFORMANCE INDEX

Normalized performance

Each finish is converted to a 0–100 value, then combined using the weighted components shown above. The PI is descriptive, not an official Lichess rating.
