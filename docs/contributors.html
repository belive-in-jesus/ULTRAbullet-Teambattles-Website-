How to read this list

The list uses the players shown in each Lichess team-battle result. Their listed points are added together. The same player is counted only once in each battle. This is a record of players shown in past results, not a full list of team members. Players may have played for different teams in different battles.

Only regular numbered UltraBullet Team Battles count here. Special events and battles without a number are not included.
