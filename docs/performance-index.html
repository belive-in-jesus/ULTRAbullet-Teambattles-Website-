HOW IT IS CALCULATED

A transparent, weighted score.

Each battle finish is converted to a 0–100 performance value: first place receives 100, last place receives 0, with the other positions spaced proportionally between them.

Average performance40%
Consistency25%
Recent performance · last 1020%
Participation · capped at 50 battles15%

Consistency rewards a stable normalized performance: it starts at 100 and decreases with the standard deviation of the competitor's results. Participation reaches its maximum contribution at 50 recorded battles. PI is descriptive, not an official Lichess rating.
