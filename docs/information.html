THE COMPETITIVE ULTRABULLET COMMUNITY

Understand the leaderboard.

This page explains which tournaments are included, how the rankings are grouped and what the statistics mean. The aim is to keep the results consistent and easy to verify.

01 / Eligibility

Which battles count?

The regular standings include completed, numbered ULTRAbullet Team Battles created by the configured tournament organiser. A tournament must match the regular battle-title pattern and have a finished Lichess status.

  • Regular numbered Team Battles are included.
  • Unnumbered and special events are excluded.
  • Alliance, qualification, Christmas, Daily Arena and restarted events do not add points to the regular rankings.
02 / Points

How are points counted?

Points are accumulated from the published Lichess tournament results. Team standings use the team results; individual standings use each player's individual result. All eligible battles contribute to the all-time totals.

  • Battles played: eligible tournaments with a recorded result.
  • Average points: points divided by recorded battles played.
  • Podiums: finishes in the top three; first places are counted separately.
03 / Ranking periods

All-time, monthly and seasonal rankings

The same underlying results can be viewed across three time ranges. Monthly rankings use UTC calendar months. Seasons are tied to official battle numbers, not to how many records happen to be available.

All-timeEvery eligible numbered battle in the collected archive.
MonthlyEligible battles grouped by calendar month in UTC.
SeasonalFixed blocks of 50 official battle numbers: Season 1 = 1–50, Season 2 = 51–100, and so on.
Important: A missing official battle number does not shift later battles into a different season. Any gaps remain attached to their original number range.
04 / Updates

When is the data refreshed?

The leaderboard data is refreshed automatically once per day through GitHub Actions, with a scheduled run at 03:00 UTC. The homepage displays the timestamp of the latest successful data generation.

The site is a public, static frontend. No Lichess API token is placed in the website files or exposed to visitors.

05 / Data quality

How should gaps be understood?

Only tournaments that can be discovered and whose results can be collected are available for the calculations. The current season view identifies missing official battle numbers where applicable. A missing record should not be interpreted as a zero-point result.

06 / Project

About this leaderboard

This independent community dashboard brings recurring Lichess UltraBullet Team Battles together in one searchable archive. It is designed for exploring long-term team and player performance, not as an official Lichess rating or title system.

The battle-result aggregation concept and original processing script are based on DarkOnCrack's Gift For Nathanael, used with permission. Tournament play and results remain on Lichess.org.
